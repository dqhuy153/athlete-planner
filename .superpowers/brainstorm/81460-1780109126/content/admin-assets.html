Asset Manager Features

  • Dual provider: Upload to R2 (presign → PUT) or Cloudinary (presign → upload → confirm)
  • Drag-and-drop zone: Drop files or click to upload, choose provider via radio buttons
  • Provider filter tabs: All / R2 / Cloudinary with counts
  • File grid: 4-column responsive grid with image previews, file size, provider badge
  • Quick actions: Copy URL (one click), Delete (with confirmation)
  • Search + type filter: Filter by filename or file type (images/videos)
  • Pagination: Bottom bar with total count and page info
