Question: JSON Format

A

Seed Format — Full Structure

JSON matches the seed data exactly. Includes bilingual fields, full instruction structure (BEGINNER + ADVANCED with steps_vi/en, form_cues_vi/en), all running phase details. AI must follow strict schema.

{ "name": "Barbell Bench Press", "vietnameseName": "Đẩy Tạ Đòn Nằm", "targetMuscleGroup": "Chest", "secondaryMuscleGroups": ["Triceps", "Shoulders"], "garminExerciseEnum": "BENCH_PRESS", "instructions": [ { "level": "BEGINNER", "steps": { "vi": ["Nằm"], "en": ["Lie down"] }, "form_cues": { "vi": ["Lưng cong"], "en": ["Arch back"] } }, { "level": "ADVANCED", ... } ] }
Complete data Matches seed exactly AI must follow strict schema
B

Simplified — Vietnamese Only, BEGINNER Default

AI only provides Vietnamese fields + basic info. System auto-fills: English translations via AI at import time, defaults to BEGINNER level, empty secondary muscles. Simpler prompt for AI.

{ "name": "Barbell Bench Press", "vietnameseName": "Đẩy Tạ Đòn Nằm", "targetMuscleGroup": "Chest", "steps_vi": ["Nằm trên ghế", "Chân chạm sàn"], "form_cues_vi": ["Lưng hơi cong", "Hít sâu"] }
Simple for AI Fewer errors System fills defaults
C

Flat — Single Instruction Level

AI provides one set of instructions (no level distinction). Admin chooses BEGINNER or ADVANCED after import. Balanced complexity.

{ "name": "Barbell Bench Press", "vietnameseName": "Đẩy Tạ Đòn Nằm", "targetMuscleGroup": "Chest", "secondaryMuscleGroups": ["Triceps"], "steps_vi": ["Nằm", "Đẩy"], "form_cues_vi": ["Lưng cong"], "steps_en": ["Lie down", "Press"], "form_cues_en": ["Arch back"], "level": "BEGINNER" }
Bilingual Moderate complexity No ADVANCED in import
